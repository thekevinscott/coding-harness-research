# Scripted coding-agent harness demos

Open-source coding-agent harnesses running in the browser with a fixed, scripted session and no model or backend.

- `pi-web/` - [agegr/pi-web](https://github.com/agegr/pi-web) (MIT) with a scripted mock backend.
- `openhands/` - [OpenHands/OpenHands](https://github.com/OpenHands/OpenHands) (MIT) mock build with a timed event driver.

Each folder is built output, modified from upstream. Upstream licenses apply.
